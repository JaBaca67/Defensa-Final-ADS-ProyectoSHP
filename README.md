# Defensa-Final-ADS-ProyectoSHP

Proyecto final de **Análisis y Diseño de Sistemas**: 8 diagramas UML del sistema SHP.

## Estructura

```
Defensa-Final-ADS-ProyectoSHP/
├── README.md                  ← este archivo (referencia general)
├── diagramas/
│   ├── 01-casos-de-uso/
│   ├── 02-clases/
│   ├── 03-comunicacion/       ← comunicación = colaboración
│   ├── 04-secuencia/
│   ├── 05-actividades/
│   ├── 06-paquetes/
│   ├── 07-componentes/
│   └── 08-despliegue/
└── documento-final/           ← documento/presentación de la defensa
```

Cada carpeta de diagrama tiene:

- `feap/` → el archivo .feap del diagrama
- `pdf/` → la imagen del diagrama exportada en PDF
- `documentacion/` → la documentación del diagrama

## Reglas para subir archivos

1. Cada diagrama va **solo en su carpeta**.
2. Nombre de archivo: `NN-nombre-diagrama_vX.ext` (sin espacios ni tildes).
   - Ejemplo: `01-casos-de-uso_v1.feap`, `01-casos-de-uso_v1.pdf`
3. Si hay varios diagramas del mismo tipo (por ejemplo, una secuencia por caso de uso), agregar el nombre del caso:
   - Ejemplo: `04-secuencia-iniciar-sesion_v1.pdf`
4. Siempre subir **el .feap, el PDF y la documentación** del diagrama.
5. Al terminar un diagrama, actualizar su estado en la tabla de arriba.
